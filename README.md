# 📖 AWESOME BOOKS <a name="about-project"></a>

**Awesome Books** This is a single page Application (SPA) built using javascript ES6 modules and HTML/CSS to manage a personal collection of books dynamically with persistent local storage.

## 🛠 Built With <a name="built-with"></a>

### Tech Stack <a name="tech-stack"></a>

<details>
  <summary>Client</summary>
  <ul>
    <li><a href=>HTML and CSS</a></li>
    <li><a href=>Javascript ES6 modules</a></li>
  </ul>
</details>

### Key Features <a name="key-features"></a>

- **Modular ES6 architecture with Object-Oriented design**
- **Single Page Application (SPA) section switching**
- **LocalStorage data persistence with unique timestamp IDs**
